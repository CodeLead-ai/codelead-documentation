# Tutorials

A tutorial takes you from nothing to a finished result, on a sample, one step at a time. After each step, it shows what you must see, so you know that the step worked. Each tutorial follows one path that works from start to end.

**In short**
- New to CodeLead: start with [Build a new app, step by step](build-a-new-app.md), or a quickstart.
- Working on existing code: start with [Change existing code with evidence](change-existing-code.md).
- Leading a team: start with [Work with agents on the board](work-with-agents-on-the-board.md), then the modernization tutorial.

## Which one to do first

| You are | Do this first | Then |
|---|---|---|
| **New to CodeLead** | [Quickstart: build a new app](../get-started/quickstart-new-app.md), about 10 minutes | [Build a new app, step by step](build-a-new-app.md) |
| **Already a user of coding agents** | [Change existing code with evidence](change-existing-code.md) | [Work with agents on the board](work-with-agents-on-the-board.md) |
| **A team lead** | [Work with agents on the board](work-with-agents-on-the-board.md) | [Modernize a .NET Framework application](modernize-a-dotnet-framework-app.md) |

## The tutorials

| Tutorial | Time | What you need |
|---|---|---|
| [Build a new app, step by step](build-a-new-app.md) | About 1 hour | Node.js 22, git, a model, and Playwright's Chromium. |
| [Change existing code with evidence](change-existing-code.md) | About 45 minutes | Windows with Visual Studio or its Build Tools, a model, the Basic Store sample, and a GitHub repository with the `gh` tool. |
| [Start a new app from a template](start-from-a-template.md) | About 30 minutes | Node.js 22, git and a model. |
| [Modernize a .NET Framework application](modernize-a-dotnet-framework-app.md) | Plan a day; most of it is waiting | Windows with Visual Studio 2022 or later, the .NET SDK, Node.js, git, a model, a Pro licence, and the Basic Store sample. |
| [Record journeys with the Analyst](record-journeys-with-the-analyst.md) | About 30 minutes | A Pro licence, Playwright's Chromium, and the Basic Store sample running. No model. |
| [Work with agents on the board](work-with-agents-on-the-board.md) | About 20 minutes | A git repository and a coding agent. A model only for CodeLead's own run at the end. |

Every tutorial needs CodeLead installed. See [Install CodeLead](../get-started/install.md). A model is a local model server, or a key for a remote provider. See [Set up local models](../how-to/set-up-local-models.md) or [Set up remote models](../how-to/set-up-remote-models.md).

## What each tutorial teaches

- [Build a new app, step by step](build-a-new-app.md): a task manager app, one verified increment at a time, with a repair and the run report.
- [Change existing code with evidence](change-existing-code.md): one business rule in the Basic Store sample, from its conventions to a pull request.
- [Start a new app from a template](start-from-a-template.md): a small template of your own, and an app built on it.
- [Modernize a .NET Framework application](modernize-a-dotnet-framework-app.md): the eight stages of a modernization, from the dossier to the audit pack.
- [Record journeys with the Analyst](record-journeys-with-the-analyst.md): one journey of the Basic Store sample, drafted, checked and replayed.
- [Work with agents on the board](work-with-agents-on-the-board.md): a board, a card, an agent's answer and proposal, your decision, and a card queued for CodeLead.

> [!TIP]
> When a step does not give what the tutorial shows, read the tip under the step. Most tips link to [Fix a stop](../how-to/fix-a-stop.md).
