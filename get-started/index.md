# Get started with CodeLead

CodeLead lets AI models write code under rules that you control. Every change is planned, checked and approved by you. Your own build and tests validate it, and CodeLead records it. These pages take you from the install to your first change.

**In short**
- Install CodeLead and connect a model: a local model server, or a key for a remote provider.
- Then pick one quickstart: VS Code, a new app, or a change to existing code. Each takes about ten minutes.
- Not sure where to start? [Choose your path](choose-your-path.md).
